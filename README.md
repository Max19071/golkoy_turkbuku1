# Hotel Resort Bodrum

React, TypeScript, Vite ve Tailwind CSS ile hazırlanmış otel tanıtım sitesi.

## Bilgisayarda çalıştırma

Node.js 22.12 veya daha yeni bir sürüm gereklidir.

```bash
npm install
npm run dev
```

Komut çalıştıktan sonra terminalde gösterilen yerel adresi tarayıcıda açın.

## Üretim derlemesi

```bash
npm run build
npm run preview
```

Derlenen dosyalar `dist` klasöründe oluşur.

## GitHub Pages

Bu projede GitHub Pages için otomatik yayımlama iş akışı hazırdır. Depoda:

1. **Settings → Pages** bölümüne girin.
2. **Source** olarak **GitHub Actions** seçin.
3. Projeyi `main` dalına gönderin.

Her `main` güncellemesinde proje kontrol edilir, derlenir ve GitHub Pages'a yayımlanır.
